## Defects and gaps found

1. **Staging cannot confirm any payment.** The Cloud Run revision has no
   `STRIPE_WEBHOOK_SECRET`, and the Stripe test account has **zero webhook
   endpoints** registered. On staging, an order will never leave
   `PENDING_PAYMENT`. This is why the run used a local API.
2. **Staging cannot complete any delivery.** It has no `R2_PRIVATE_BUCKET`
   (held back by DEC-038 pending Q-012), and `delivered` requires a stored proof
   photo. The local `.env` already points at a real private bucket
   (`banhao-dev-pod-private`), so one exists in R2 despite that decision —
   worth reconciling.
3. **Recurring tick is off.** Payment confirmation, dispatch, offer expiry and
   notifications all run inside the tick. With the Worker fail-closed, nothing
   moves on its own: each stage above needed a manual tick.
4. **Customer notifications are not customer-readable.** `title` is the raw
   event type (`OrderDelivered`, `OrderPickedUp`), `body` is null, and
   delivery-sourced events carry no `orderId`. This is recorded as deliberate in
   `outbox-dispatch.service.ts` (no title convention exists), but it is not
   launch-quality.
5. **Operator flows cannot be exercised.** `platform_staff` has **no rows**, so
   refunds (`POST /admin/supervisor/orders/:id/refund`), case handling and
   delivery failure have no user who can call them. A customer cancel at `PAID`
   does not refund by itself (DEC-058 makes refunds operator-executed), so
   without staff a cancelled paid order has no refund path.
6. **One rider identity is also a customer.** The fixture rider shares the
   customer's account. Dispatch offered the customer their own order. Fine for a
   test, but nothing prevents it.

## Not exercised in this run

App UI (customer, merchant, driver), refunds and reconciliation, payment
failure and expiry, customer cancellation, delivery failure, no-rider
escalation, Stripe's own network delivery to a real endpoint (the signed event
was the real Stripe event, delivered by the script), and the Docker SQL suites.
