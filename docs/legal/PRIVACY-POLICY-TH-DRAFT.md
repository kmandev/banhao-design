# นโยบายความเป็นส่วนตัว BANHAO | บ้านเฮา — ฉบับร่าง

```
ฉบับร่าง — ยังไม่ประกาศใช้ — ไม่ใช่คำปรึกษากฎหมาย
ร่างโดย Claude ตาม DEC-068 E2 (2026-11-02) จากข้อมูลที่ระบบเก็บจริง
ณ main @ 44349c48 เจ้าของต้องตรวจทุกข้อก่อนใช้
```

## หมายเหตุสำหรับเจ้าของ (ลบออกก่อนประกาศ)

- ข้อความใน `[วงเล็บเหลี่ยม]` คือข้อมูลที่ต้องกรอก หรือข้อที่ต้องตัดสินใจ
- ร่างนี้อิงจาก schema และโค้ดจริง ไม่ได้อิงจากแบบฟอร์มทั่วไป ถ้าระบบเปลี่ยน
  (เช่น เปิดเก็บ GPS ระหว่างส่ง ตาม DEC-064) ต้องแก้ร่างนี้ด้วย
- Q-012 (ฐานทางกฎหมายสำหรับตำแหน่งไรเดอร์) ยัง `OPEN / LEGAL_REVIEW_REQUIRED`
  เจ้าของยกเลิกการจ้างทนายแล้ว ร่างนี้จึงยังไม่ได้รับการตรวจทางกฎหมาย
- การลบรูปหลักฐานอัตโนมัติ (90 วัน, DEC-039) **ยังปิดอยู่**
  (`POD_RETENTION_PURGE_ENABLED=false`) ต้องเปิดก่อนประกาศข้อ 6
  ไม่เช่นนั้นข้อความจะไม่ตรงกับความจริง
- ระยะเวลาเก็บข้อมูลคำสั่งซื้อและบัญชี ให้ยืนยันกับนักบัญชี (DEC-067 S7)

---

## 1. เราคือใคร

BANHAO | บ้านเฮา ("เรา") ให้บริการแอปสั่งอาหารและจัดส่งในอำเภอบุณฑริก
จังหวัดอุบลราชธานี ผ่านแอปลูกค้า แอปไรเดอร์ และเว็บสำหรับร้านค้า

ผู้ควบคุมข้อมูลส่วนบุคคล: `[ชื่อบุคคลหรือนิติบุคคล]`
ที่อยู่: `[ที่อยู่]`
ติดต่อเรื่องข้อมูลส่วนบุคคล: `[อีเมล]` / `[เบอร์โทร / LINE]`

นโยบายนี้อธิบายว่าเราเก็บข้อมูลอะไร ใช้ทำอะไร ส่งให้ใคร เก็บนานเท่าไร
และคุณมีสิทธิ์อะไรตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

## 2. ข้อมูลที่เราเก็บ

### ลูกค้า

| ข้อมูล | ใช้ทำอะไร |
|---|---|
| เบอร์โทรศัพท์ | เข้าสู่ระบบด้วยรหัส OTP และให้ร้านหรือไรเดอร์ติดต่อเรื่องออเดอร์ |
| ชื่อที่แสดง | แสดงในแอปและบนออเดอร์ |
| อีเมล | ส่งให้ผู้ให้บริการชำระเงินเพื่อออกใบเสร็จ และ**จำเป็นสำหรับการคืนเงิน PromptPay** (ผู้ให้บริการชำระเงินจะส่งอีเมลขอเลขบัญชีเพื่อโอนเงินคืน) |
| ที่อยู่จัดส่ง ชื่อและเบอร์ผู้รับ จุดสังเกต คำแนะนำการส่ง และพิกัดของที่อยู่ | จัดส่งอาหาร |
| ประวัติคำสั่งซื้อ (รายการอาหาร ราคา ค่าส่ง ค่าบริการ เวลา สถานะ) | ให้บริการ คืนเงิน แก้ปัญหา และทำบัญชี |
| สถานะการชำระเงิน (ไม่ใช่ข้อมูลบัตรหรือบัญชีธนาคาร) | ยืนยันว่าชำระแล้ว และคืนเงิน |
| การแจ้งเตือนในแอป | แจ้งสถานะออเดอร์ |
| รูปถ่ายหลักฐานการส่ง (ถ่ายโดยไรเดอร์) | ยืนยันว่าส่งแล้ว และแก้ข้อพิพาท |

เรา**ไม่**เก็บเลขบัตรหรือเลขบัญชีธนาคารของคุณ การชำระเงินทำผ่านหน้าของ
ผู้ให้บริการชำระเงินโดยตรง เรา**ไม่**ติดตามตำแหน่ง GPS ของลูกค้าแบบสด

### ไรเดอร์

| ข้อมูล | ใช้ทำอะไร |
|---|---|
| เบอร์โทรศัพท์ ชื่อ-นามสกุล ประเภทรถ ทะเบียนรถ | สมัครและยืนยันตัวตน แสดงให้ลูกค้าและร้านเห็นระหว่างส่ง |
| เอกสารประกอบการสมัคร `[ระบุ: บัตรประชาชน ใบขับขี่ ฯลฯ]` | ตรวจคุณสมบัติก่อนอนุมัติ |
| สถานะออนไลน์ และ**ตำแหน่งล่าสุดเพียงจุดเดียว** | หาไรเดอร์ที่อยู่ใกล้ร้านเพื่อเสนองาน เราเก็บเฉพาะตำแหน่งล่าสุด ทับของเดิมทุกครั้ง **ไม่เก็บประวัติเส้นทาง** `[ยืนยันว่าเก็บเฉพาะตอนออนไลน์ หรือเฉพาะระหว่างส่ง ตาม DEC-064]` |
| ประวัติงาน ข้อเสนองานที่รับหรือปฏิเสธ ค่าส่งที่ได้ | ให้บริการและจ่ายค่าตอบแทน |
| รูปหลักฐานการส่ง | ยืนยันว่าส่งแล้ว |
| `[บัญชีธนาคารสำหรับรับค่าตอบแทน — เมื่อระบบจ่ายเงินพร้อม]` | จ่ายค่าตอบแทน |

### ร้านค้า

ข้อมูลร้าน (ชื่อ ที่อยู่ พิกัด เวลาเปิด-ปิด เมนู ราคา รูปภาพ) เบอร์โทรของ
สมาชิกร้านที่ใช้เข้าระบบ และประวัติออเดอร์ `[เมื่อใช้ Stripe Connect:
ร้านกรอกข้อมูลยืนยันตัวตนและบัญชีธนาคารกับ Stripe โดยตรง เราไม่เห็นข้อมูลนั้น]`

### ข้อมูลทางเทคนิค

บันทึกการใช้งานระบบ (log) เช่น เวลาที่เรียกใช้ เส้นทาง API และรหัสผลลัพธ์
เพื่อดูแลความปลอดภัยและแก้ปัญหา บันทึกการตรวจสอบ (audit log) ของการกระทำ
สำคัญ เช่น การเปลี่ยนสถานะร้าน การยกเลิก และการคืนเงิน

## 3. ฐานทางกฎหมายที่เราใช้

- **สัญญา:** ข้อมูลที่จำเป็นต่อการรับ ส่ง และชำระเงินค่าอาหาร
- **หน้าที่ตามกฎหมาย:** เอกสารบัญชีและภาษี
- **ประโยชน์โดยชอบด้วยกฎหมาย:** ความปลอดภัยของระบบ ป้องกันการทุจริต
  และแก้ข้อพิพาท (เช่น รูปหลักฐานการส่ง บันทึกการตรวจสอบ)
- `[ตำแหน่งไรเดอร์: ระบุฐาน — Q-012 ยังไม่ได้ข้อยุติ]`

## 4. เราส่งข้อมูลให้ใคร

| ผู้รับ | ข้อมูล | เหตุผล |
|---|---|---|
| ร้านค้าที่คุณสั่ง | ชื่อ รายการอาหาร หมายเหตุ | เตรียมอาหาร |
| ไรเดอร์ที่รับงาน | ชื่อผู้รับ เบอร์โทร ที่อยู่ พิกัด คำแนะนำการส่ง | จัดส่ง |
| ลูกค้าของออเดอร์ | ชื่อไรเดอร์ ประเภทรถ ทะเบียน รูปหลักฐานการส่ง | ติดตามและยืนยันการส่ง |
| Stripe (ผู้ให้บริการชำระเงิน) | ยอดเงิน อีเมล เลขอ้างอิงออเดอร์ | รับชำระและคืนเงิน |
| Supabase (ฐานข้อมูลและระบบเข้าสู่ระบบ, เซิร์ฟเวอร์ที่สิงคโปร์) | ข้อมูลทั้งหมดในข้อ 2 | เก็บข้อมูลแทนเรา |
| Google Cloud (เซิร์ฟเวอร์ API) | ข้อมูลที่ผ่านระบบ | ประมวลผลแทนเรา |
| Cloudflare (เก็บรูปหลักฐานการส่ง, งานตามเวลา) | รูปถ่าย | เก็บไฟล์แทนเรา |
| `[ผู้ให้บริการ SMS OTP — เมื่อเปิดใช้]` | เบอร์โทร | ส่งรหัส OTP |
| หน่วยงานรัฐ | ตามที่กฎหมายกำหนด | หน้าที่ตามกฎหมาย |

ผู้ให้บริการบางรายเก็บข้อมูลนอกประเทศไทย (เช่น สิงคโปร์) เราเลือกผู้ให้บริการ
ที่มีมาตรการคุ้มครองข้อมูลตามมาตรฐานสากล เรา**ไม่ขาย**ข้อมูลส่วนบุคคล

## 5. ความปลอดภัย

- รูปหลักฐานการส่งอยู่ในที่เก็บแบบส่วนตัว เปิดดูได้ด้วยลิงก์ที่หมดอายุเร็ว
  และระบบลบข้อมูลตำแหน่ง (EXIF) ออกจากรูปก่อนอัปโหลด
- ผู้ใช้แต่ละคนเห็นเฉพาะข้อมูลของตัวเอง ด้วยการควบคุมสิทธิ์ระดับฐานข้อมูล
- การเปลี่ยนแปลงสำคัญถูกบันทึกและแก้ไขย้อนหลังไม่ได้

## 6. เราเก็บข้อมูลนานเท่าไร

| ข้อมูล | ระยะเวลา |
|---|---|
| รูปหลักฐานการส่ง | 90 วันนับจากส่งถึง จากนั้นลบอัตโนมัติ รูปที่ถ่ายใหม่แทนหรือไม่ได้ใช้ ลบภายใน 7 วัน |
| ตำแหน่งไรเดอร์ | เก็บเฉพาะจุดล่าสุด ถูกเขียนทับทุกครั้ง |
| คำสั่งซื้อ การชำระเงิน และบัญชี | `[ตามกฎหมายบัญชีและภาษี — ยืนยันกับนักบัญชี]` |
| ข้อมูลบัญชีผู้ใช้และที่อยู่ | ตลอดที่ใช้บริการ จนกว่าคุณขอลบ (ยกเว้นข้อมูลที่กฎหมายให้เก็บต่อ) |

## 7. สิทธิ์ของคุณ

คุณมีสิทธิ์ขอเข้าถึง ขอสำเนา ขอแก้ไข ขอลบ ขอระงับการใช้ คัดค้าน
และขอโอนย้ายข้อมูลของคุณ ตาม PDPA และร้องเรียนต่อสำนักงานคณะกรรมการ
คุ้มครองข้อมูลส่วนบุคคลได้

ติดต่อเราที่ `[อีเมล / LINE]` เราจะตอบภายใน 30 วัน

ข้อจำกัด: คำสั่งซื้อและรายการบัญชีที่เกิดขึ้นแล้วลบไม่ได้ เพราะกฎหมายบัญชี
กำหนดให้เก็บ เราจะลบหรือทำให้ไม่ระบุตัวตนในส่วนที่ลบได้
