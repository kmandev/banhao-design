ADMIN — OPERATIONS — PHASE I
BANHAO | บ้านเฮา · one design package for the whole operator surface · design only, no implementation
Read-only recon against kmandev/banhao-design@main: docs/ROADMAP.md, docs/TODO.md, docs/CURRENT_STATUS.md, docs/PAYMENT_LIFECYCLE.md, docs/SETTLEMENT_MODEL.md, docs/design/BANHAO-UX-SPEC-V1.md, the payment / ledger / audit / reconciliation migrations, apps/admin/src, apps/api/src/modules/** and CapabilitiesService. Operator-facing copy is Thai; every annotation is English. No API, schema, migration, config or source file was created or modified.
Three boundaries this package never crosses. An operator cannot set SUCCESS or REFUNDED — both are reachable only from a signature-verified webhook (CON-002), so no screen here carries a control that writes them. No order state is added: the four exception states sit in the CHECK constraint and stay unimplemented (DEC-APP-006). And no amount, rate or cycle is invented — every settlement and commission figure renders as a decision dependency, not a number.
