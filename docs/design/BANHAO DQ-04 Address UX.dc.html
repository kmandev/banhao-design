DQ-04 — Address Create / Edit UX
Design specification for the missing customer address creation and edit experience. The backend contract, database and RLS are unchanged; this document defines only the customer-facing screens, states and copy needed so an authenticated account can establish a default address and complete an ONLINE order.

Navigation
