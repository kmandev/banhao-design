## Problems found and fixed

1. **Two `@types/react` majors collided** (admin on React 19, Expo pinned to 18), breaking every JSX type in the customer app. Aligned the monorepo on React 18 via `pnpm.overrides`. 2. **`@banhao/ui` began importing React Native**, which broke the Next.js admin build (Flow syntax in `react-native/index.js`). Added a `./theme` export so web consumers take framework-agnostic tokens only.
3. **Metro could not resolve `@babel/runtime`** under pnpm's isolated store. Added a monorepo `metro.config.js` (watchFolders + nodeModulesPaths + symlinks) and an explicit dependency.
4. **Jest's `transformIgnorePatterns` never matched** because pnpm nests everything under `.pnpm/`; rewrote the pattern against the store path.
5. **A navigation test failed for a real reason** — `isSupabaseConfigured` is false in tests, so `AuthProvider` short-circuits. Setting `process.env` at runtime could not fix it: `babel-preset-expo` inlines `EXPO_PUBLIC_*` at transform time. Mocked the module boundary instead.
